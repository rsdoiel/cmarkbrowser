Installing cmarkbrowser

cmarkbrowser is a single program written in Go. There is no release yet, so you build it from the source.

Requirements

  • Go 1.27.3 or later
  • GNU Make 3 or later (optional; the commands below are what it runs)
  • Pandoc 3.1.11 or later, only to build this website

Build and install

git clone https://github.com/rsdoiel/cmarkbrowser
cd cmarkbrowser
make
make install

make builds bin/cmarkbrowser. make install copies it to $HOME/bin, or to prefix/bin when you run make install prefix=/usr/local. Without make:

go build -o bin/cmarkbrowser ./cmd/cmarkbrowser

Run the tests with make test.

Try it

cmarkbrowser -version
cmarkbrowser https://rsdoiel.github.io/blog/index.md
cmarkbrowser -dump https://dave.writersweb.org/

The browser needs a terminal. -dump prints a page and its links and works in a pipe. See the User Manual for the keys.

Editing pages

Press e to edit the page you are reading. cmarkbrowser starts the editor named by $VISUAL, else $EDITOR, and guesses none, so set one:

export EDITOR=nano

Files it writes

cmarkbrowser has no settings file. In the folder you start it from it keeps history.md (every page you visit, newest first) and, if you press m, bookmarks.md. -no-history turns the history off. A copy of a remote page that you edit goes in your Downloads folder.

Building this website

make website

writes an HTML page beside each Markdown page, index.md, .nojekyll and .well-known/toc.opml. make publish merges into the gh-pages branch and pushes it. See BonBon for what the Markdown side is for.
